# ESP32 + MIKROE UV 5 Click / AS7331

The current UV module is **MIKROE-5535**, based on AS7331, not the SparkFun
breakout used in an early footprint draft. The current firmware reads UVA,
UVB and UVC in one-shot mode. See [complete wiring](README.md).

| UV 5 Click label | ESP32 connection |
|---|---|
| 3.3V | 3V3 |
| GND, both headers | GND |
| SDA | GPIO 21, shared I2C data |
| SCL | GPIO 22, shared I2C clock |
| SYN, RDY | Unconnected; current driver does not use these GPIO signals |
| CS / ClickID and all other unused mikroBUS pins | Unconnected |
| 5V position | Unconnected; do not use as this board's supply |

The firmware expects address `0x74`; retain the default A0/A1 jumper positions.
A mikroBUS motherboard is not required. Use the **printed signal labels**, not
the apparent position of a header in a rotated photograph.

The manufacturer's [pinout and board data](https://www.mikroe.com/uv-5-click)
specify a 3.3 V supply and 28.6 x 25.4 mm board. The
[v100 schematic](https://download.mikroe.com/documents/add-on-boards/click/uv-5-click/UV_5_click_v100_Schematic.pdf)
shows 2.2 kohm I2C pull-ups and a power LED connected to the supply: the current
firmware cannot switch that LED off. Include it when checking combined pull-ups
and optical leakage. Do not desolder parts as a routine setup step.

Verify `uv_available` and the AS7331 diagnostic state. A successful I2C scan is
not a calibration. An outdoor UVC residual may reflect dark offset, spectral
cross-sensitivity or other uncertainty; calibrate with appropriate references
in the [final assembly](../calibration/README.md).
